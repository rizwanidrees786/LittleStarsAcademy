# Little Stars Academy — Phase 1

## APK kaise banayein
1. Android Studio (Koala / Ladybug ya naya) install karein.
2. File → Open → is folder (LittleStarsAcademy) ko select karein. Pehli baar Gradle sync internet se libraries download karta hai.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK yahan milti hai: app/build/outputs/apk/debug/app-debug.apk — phone mein copy karke install karein.

## Phase 1 mein kya hai
- Animated splash ("Developed by Rizwan Idrees"), animated background
- Teen profiles: Aliha (KG-II), M Affan (KG-I), Aenan (3 saal). Data bache ke NAAM se juda hai, character badalne se nahi badalta
- 24 original characters, har ek apna naam bolta hai
- Learn & Play: letters, colors, shapes, counting, addition, subtraction, words, opposites, Urdu→English (level har bache ke hisaab se)
- Ghaltiyan yaad rakhna: kamzor skills zyada aate hain, ghalat jawab dobara poochhe jate hain
- 10-sawal ka test, progress screen, parent zone (PIN default 1234)
- Kahaniyan (English + Urdu), jokes, paheliyan
- Awaaz: phone ki offline TTS. Urdu awaaz ke liye phone mein Urdu voice data install honi chahiye
